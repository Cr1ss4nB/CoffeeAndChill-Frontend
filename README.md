# CoffeeAndChill-Frontend
Frontend de Coffee &amp; Chill. CoffeeAndChill es una aplicación web para cafeterías creativas que integra menú digital, gestión de pedidos, inventario y reservas de talleres artísticos. Ofrece roles de administrador y empleado, seguimiento de estados y una experiencia visual enfocada en un ambiente relajado donde el café y el arte se combinan.
